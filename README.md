# Windows M3U8 提取器

这是一个 Windows 图形界面的 M3U8 提取工具。

## 功能

1. 输入影视作品名称
2. 自动搜索作品
3. 选择对应作品
4. 自动进入详情页
5. 优先提取网站提供的：
   
   `copy_dyttm3u8[]`

6. 如果优先方式没有找到，则自动使用通用 M3U8 提取方式
7. 自动识别第几集
8. 支持：
   - 提取全部集数
   - 提取指定单集
9. 自动去重
10. 自动按照集数排序
11. 自动复制到剪贴板
12. 显示最终结果

## 输出格式

```text
https://example.com/1/index.m3u8#作品名第1集
https://example.com/2/index.m3u8#作品名第2集
https://example.com/3/index.m3u8#作品名第3集
